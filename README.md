# Research Center 포털 사용법

리서치 보고서를 찾고, 읽고, 투자 지표를 직접 계산해 보는 학습 포털입니다. 화면의 보고서, 일정, 수치는 모두 학습용 예시입니다.

## 열기

1. `index.html`을 더블클릭하거나 브라우저로 끌어다 놓습니다. 인터넷 연결이나 별도 설치는 필요하지 않습니다.
2. 자료실과 보고서의 PDF 다운로드가 동작하려면 `index.html`과 같은 위치에 `files` 폴더가 있어야 합니다.

## 화면 구성

위쪽 고정 메뉴에서 각 구역으로 이동합니다. 스크롤하면 현재 구역이 메뉴에 표시되고, 화면이 좁으면 `메뉴` 버튼으로 펼칩니다(Esc로 닫기).

| 메뉴 | 할 수 있는 일 |
|---|---|
| 홈 | 포털 소개와 현황(예시 보고서 수, 리서치 분야 수, 핵심 용어 수) |
| 최신 이슈 | 글로벌 증시 주요 뉴스 5건 카드(2026.11.18 기준). 요약은 직접 정리한 것이고, 출처 링크는 새 탭에서 열림. 자동 갱신되지 않으므로 `index.html`의 `#issues` 구역을 직접 고쳐서 교체 |
| 리서치 분야 | 매크로·산업·기업 분석·증시 전망 4개 분야 소개. `○○ 보고서 보기`를 누르면 해당 분야만 걸러서 보고서 구역으로 이동 |
| 보고서 | 분야 필터, 발간일 정렬(최신순/오래된순), 제목 검색. 조건에 맞는 건수가 표시되고, 카드의 `PDF 다운로드`로 파일을 받음 |
| 읽는 법 | 투자의견, 목표주가, 컨센서스, EPS, BPS, PER, PBR, ROE, 배당수익률, 어닝 서프라이즈·쇼크 설명. 항목을 눌러 펼침 |
| 지표 일정 | 월별 주요 경제 지표 발표 일정(2026년 11월, 12월, 2027년 1월). 월 버튼으로 전환, 중요도는 ★ 1~3개. 실제 발표일은 각 기관의 공식 일정을 확인 |
| 지표 계산기 | 주가·EPS·BPS·주당배당금(DPS)을 입력하면 PER, PBR, ROE, 배당수익률을 계산 |
| FAQ | 검색어 입력과 카테고리 버튼(전체·보고서 이용·보고서 읽는 법·경제 지표·주식 지표·채권 지표·위험 지표)으로 질문을 거르고, 질문을 눌러 답을 확인. 둘을 함께 쓰면 두 조건에 모두 맞는 질문만 남음 |
| 자료실 | `files` 폴더의 자료 목록. 파일명, 설명, 용량을 확인하고 `다운로드` 버튼으로 바로 내려받음(저장 이름은 한글) |

### 보고서 찾기
1. `전체` 또는 분야 버튼으로 분야를 고릅니다.
2. 정렬 상자에서 `발간일 최신순`이나 `발간일 오래된순`을 고릅니다.
3. `제목 검색`에 단어를 입력합니다(제목만 검색됩니다). 결과가 없으면 필터나 검색어를 바꾸라는 안내가 나옵니다.

### 지표 계산기
- 모든 금액은 같은 통화 단위로 입력합니다.
- 계산식: PER = 주가 ÷ EPS, PBR = 주가 ÷ BPS, ROE = EPS ÷ BPS × 100(단순 환산), 배당수익률 = DPS ÷ 주가 × 100.
- 입력하는 즉시 결과가 바뀌며, 필요한 값이 빠졌거나 계산할 수 없는 값(예: EPS가 0 이하)이면 결과 칸에 그 이유가 표시됩니다.
- `예시 값 채우기`는 가상의 숫자를 넣고, `초기화`는 입력을 모두 지웁니다.
- 입력한 값은 이 화면 안에서만 계산되며 저장되거나 외부로 전송되지 않습니다. 새로 고치면 사라집니다.

## 폴더 구성

```
index.html                       포털 본체
files/                           다운로드 자료(PDF 등)
  research-report-guide.pdf      리서치 보고서 이용 안내서
  investment-indicator-glossary.pdf   투자 지표 용어 해설집
이전버전/                        링크 수정 전 index.html 사본
research-center-v1.html          이전 시안
research-center-v2.html          v2 원본 시안
research-center-v2-a-ivory-forest.html   v2 색상 시안 A
research-center-v2-b-violet-night.html   v2 색상 시안 B
research-center-v2-c-ink-coral.html      v2 색상 시안 C
```

## 자료 추가·교체

- PDF, Word, XLSX 등 내려받을 파일은 `files` 폴더에 넣습니다. 파일명은 한글과 공백 없이 영문 소문자와 하이픈만 씁니다(예: `research-report-guide.pdf`).
- 자료실 목록은 `index.html`의 `자료실` 구역에 파일마다 항목(`<li>`) 하나로 적혀 있습니다. 파일을 추가하면 기존 항목을 복사해 아래 네 가지를 바꿉니다.
  - 파일명(화면에 보이는 한글 이름)
  - 설명
  - 용량(파일 크기를 KB 단위로 직접 적음)
  - 링크: `href="files/영문파일명"`과 `download="저장될 한글 이름"`
- 링크는 `files/파일명` 상대 경로이고 `download` 속성이 있어, PDF도 새 창으로 열리지 않고 바로 내려받아지며 `download`에 적은 이름으로 저장됩니다.
- 목록은 `files` 폴더를 자동으로 읽지 않으므로, 파일을 넣거나 지울 때 항목도 함께 고쳐야 합니다.
- 보고서 카드의 `PDF 다운로드`는 보고서마다 `files/<보고서 ID>.pdf`를 가리킵니다(예: `files/macro-2026-11.pdf`). 해당 이름으로 PDF를 넣으면 연결됩니다.

## 현재 연결 상태

- 자료실에는 `files` 폴더에 실제로 있는 PDF 2개(투자지표_용어해설집, 리서치_이용안내서)만 표시됩니다. 예전에 자리만 잡아 두었던 항목 4개(`indicator-calendar-sample.xlsx`, `valuation-practice-sheet.xlsx`, `research-rating-definitions.pdf`, `compliance-notice.pdf`)는 목록에서 뺐고, 원래 모습은 `이전버전/index.html`에 있습니다.
- 보고서 8건의 PDF(`macro-2026-11.pdf` 등)는 아직 `files`에 없어 내려받을 수 없습니다.

## 화면 조작
- 모바일(폭 980px 이하)에서는 상단 메뉴가 ≡ 버튼으로 접히고, 항목을 누르면 자동으로 닫힙니다.
- 지금 보고 있는 구역의 메뉴 항목이 강조됩니다.
- 상단의 해/달 버튼으로 다크·라이트 모드를 바꿉니다. 오른쪽 아래 `맨 위로` 버튼은 스크롤하면 나타납니다.

## 개인정보
지표 계산기에 입력한 값은 저장하지도, 외부로 보내지도 않습니다. 브라우저에 남기는 것은 다크·라이트 선택값(`rc-theme`) 하나뿐입니다.
